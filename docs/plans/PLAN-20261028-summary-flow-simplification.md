## 1. 要解决的问题与目标

七步中只有选材和成稿需要模型；命令变少主要减少操作，消除重复输入、避免没有收益的独立选材才可能降低模型成本。原文素材包应帮助成稿取材和组织，回源位置同时服务核查，不能仅凭“方便质检”证明多一轮调用值得保留。

- 普通源沿现役单轮流程；复杂长源作为两阶段候选，只有实测收益值得额外消耗时才保留。暂不新增模型分类调用，也不凭一次小样本改全库路由阈值。
- 两阶段成稿以原文素材包为直接输入；默认不另附全文、不要求完整重读源文件。有指代、条件、时序或数字归属疑点时按行段局部回查。
- 首个候选采用“已选原文素材 + 未选区间原文附录”：覆盖可得文本，减少“全文 + 重复素材”双份投喂。全文仍保留供校验、局部回查和独立复核；读图、表格缺源不会被附录补全。
- 模型只选位置、归组、关联和疑点；程序逐字提取，成稿按需编辑，不强制逐条转述。未选区间不能直接当无价值信息丢掉。
- 不把包做完整当作选材或成稿质量通过；不以输出字数、条目数、压缩率和源稿比例约束生成。是否省 token、费用和时间分别取证，不保证两阶段比单轮便宜。

## 5. 有界验证、成本与保留条件

1. **先确认输入成立，再花模型调用。** 优先复用 N6 同版冻结源和原文素材包；读取范围、契约或包版本不一致时不混用。用确定性检查验证素材 + 附录的文本范围、版本绑定、装配次数与真实派工输入；“包里有全文信息”只算输入可得，不算语义完整。
2. **先一源，必要时第二源。** 优先已有 S3 字幕与 D1 长文章，先一源检验新写作输入；无明显输入收益或新增重要失真先停定位，不同时铺格式/容量搜索。第一源值得继续时再做第二源；同条件有效产物尽量复用，无效基线才补生成，不重跑已完成提炼凑流程。
3. **比较两个问题。** 新完整包消费 vs 旧“全文 + 包”检查是否消除重复及损害质量；新两阶段 vs 现役单轮检查选材是否值得额外调用。普通源先做路由回归，只有需要核对额外提炼无收益时才补真实负样本。尚无真实多块证据时，结论限已测单块范围。
4. **独立语义核验仍看源与稿。** 先从同版可得源确定重要信息，再核对主线外独有内容、条件/反例、因果/时序、数字对象及 ASR 疑点；反查成稿强主张是否受源支持，沿用固定取材问题。模型审者给出可定位证据，争议项单列，不将偏好或分数当作者认可；只看包的复核不能证明包没漏。
5. **核算完整消耗。** 所有生成阶段记录输入/输出、调用/失败/重试、实际回源范围、token usage、可得费用和耗时；机械装配与复核单记，同时给出生成合计与含复核总计。字符统一含空白的 Unicode 口径，token/费用/耗时不可得写 `unknown`，不得用字符估算后宣称已省钱。复用既有包时同时列“本次新增消耗”和“从源重跑完整流程消耗”，不能把历史提炼当零成本。
6. **提前登记有界批次。** 生成前写定源/版本、两臂输入、调用额度、可取得的费用/时间预算与停止点；不继承或重置耗尽的 S1 额度。缺明确预算或缺 usage 时只能报告可测收益与缺口，不宣称成本验收通过；本次文档工作不运行模型。
7. **保留条件。** 相对旧重复输入必须消除可定位的全文重复，重要信息与关系不因新消费方式丢失、无新增严重失真；至少两个不同适用源相对单轮有可定位质量收益，且完整生成成本在事前登记的可接受预算内，才支持该类源保留两阶段。未达到时保留单轮或继续关闭；命令数减少、包复制正确和有限复核通过均不能单独支持启用。

两阶段读取“完整包”仍可能接近再读一遍全文，包内重叠也可能增加输入；收益假设是组织取材与避免双份投喂，不能预先写成总成本低于单轮。若完整输入仍超容量，先记录实际边界并保留待办，不删未选区间，也不自动增加统稿层数。
