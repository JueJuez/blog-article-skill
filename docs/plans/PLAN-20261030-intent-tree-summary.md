## 1. 要解决的问题（全部来自 F7 实测，非假设）

| 失败模式 | 实测证据 |
|---|---|
| 单轮丢主干 | cur 臂 P1 遗漏 6 处（5/6 源）、内容级失真 7 处 |
| 组合流程无选材权 | po 压缩率 63–116%（P1/P5 达 116% **超源文**），P2 遗漏计分被厚度污染 |
| 写作慢 | 5.5–15.2 分钟/篇，输出长度线性入时间（厚度即速度） |

根因（机制级，四条）：① 补稿协议零改动只有「改写已含」一个出口，结构上不允许丢；
② 机械自查对**全部**素材条目拦截；③ 盲比审计只罚丢不罚肿；④ 提炼产物是平面清单，
无层级、无意图、无主次档位。「忠实 = 不丢」的等式把摘要的选材权收走了。

**三轴契约（本计划的验收总纲）**：准确性（不失真不编造，绝对）；主干完整（论点/方法/
结论级内容不丢，绝对）；**细节选材权（该丢的丢，且丢得有意）**——本计划补第三轴。

## 2. 方案：意图树提炼 + 意图驱动写作

链路骨架不动（提炼 → pack_only 装配 → po 写作 → 机械自查 → 定向补稿 → 只插不改核验），
改动集中在**提炼契约 v5→v6** 与**写作/自查/补稿契约**：

### 2.1 提炼契约 v6（`prompts/distill` 升版）

- 新增 `hierarchy`：**树形随源形态自适应**——有显式章节的源用 章节 → 小节 → 节点；
  无显式章节的口播/直播用**话题分段**（聊到哪说到哪 = 每个话题一个节点，各记各的
  用意，树退化为话题列表；话题 = 有独立用意的最小单元且有推进，纯承接过渡不算，
  防碎化）。每级一句 `intent`（作者用意/目的）；v5 的 `mainline` 并入树根——
  **根 intent 可空**（纯话题拼盘的源没有全局主线），话题节点 intent 必填（填不出
  用意的不配成节点）。
- `items` 挂 `node_id`，新增 `tier` 三档：
  - `trunk`：该节点用意成立所必需（主干，必落点）；
  - `support`：支撑材料，写作端按主线取舍；
  - `drop`：默认丢——重复表述、元信息、过程叙述、寒暄、与主线无关的岔题。
- **忠实度边界**：`intent` 是笔记者对作者用意的推断，只用于组织选材与判定舍弃，
  **不进稿**；成稿不得把意图写成作者的明确主张。条目正文仍逐字取自同版源（不变）。
- **无实质内容出口**：「无结构」不降级——口播按话题分段仍是树。唯一降级出口是
  提炼者显式判 `no_substance`（纯寒暄/无实质内容），该篇走轻量笔记出口，不硬造树。
  **话题回跳**（A→B→A′）：同一话题的两段归同一节点，非连续区间——复用现役
  `source_spans` 的非连续语义（标界不伪装连续引文），零新增机制。

### 2.2 写作契约（模板段落增量）

- 明示选材权：trunk 必落点；support 按主线取舍（丢了不需理由）；drop 默认丢。
- 主干完整性机制：非 drop 节点在稿内必须有落点，或写作端显式声明舍弃及理由
  （「整章静默消失」在结构上不可能发生——D1 教训的机械化）。
- **不设字数/压缩率生成硬闸**（防 S2/S5 为凑数砍内容的复辙）；压缩率只做验收观察项
  （目标带：中位 ≤ 源文 50%，超出须解释，不自动判败）。

### 2.3 自查与补稿

- `shared/note_coverage.py` / `scripts/check_note_coverage.py`：**仅 `trunk` 条目进拦截**
  （label 3-gram 阈值 0.2 冻结不变）；support/drop 进 info 报告。
- 补稿协议**三出口**：①改写已含；②**核实为可舍弃（记录一句理由）**——新增；
  ③缺才补（纯插入，`--verify-insert-only` 核验不变）。

### 2.4 审计协议（双向，修订 F7 单向协议）

- 主干保留：树节点 → 稿内落点矩阵（缺落点 = P1）；
- **压缩质量（新增）**：该丢的丢了没有——元信息、寒暄、重复、过程叙述残留计数 +
  压缩率；与遗漏维度对价计分；
- 准确性：确定性失真/待确认标注（不变）；元数据误判（frontmatter 注入的链接/作者/日期）
  不计稿方失真（F7 解盲教训）。

## 3. 边界

- **首版不含 >40k 多块源**（树跨块统稿另立项）；numeric_dense/numeric_heavy 熔断不变；
  4k 以下仍单轮。话题分段不改变调用次数：分段发生在同一次提炼调用内，模型只多产出
  层级与意图标注，条目正文仍程序逐字提取。
- 契约 v6 生效后旧 v5 pack 由既有版本门自动隔离，**不做兼容消费**；生产开关仍 0，
  试点走显式评估路径（F7 同款隔离队列/pack/产物，不碰 vault）。
- 意图树的层级数不设硬性要求（源有多少层就多少层）；树是中间产物，稿内最多保留目录级
  导航，不整棵进稿。
