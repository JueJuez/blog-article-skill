# DECISION-20261015-note-evidence
## 背景
用户授权开始批次3；词和数字命中不能证明引文、资源对应或复算正确。
## 决策
- 复用verifier/content_signals和现有审计入口，证据检查为纯函数，不新增模型调用或生产保存链路。
- 仅明确原话字段/金句区校验逐字来源；TL;DR、普通引号、示例代码不当原话。
- 空白与列明的全半角标点可规范化；跨段省略必须显式标记，ASR实体修正转复核。
- 资源仅对源内明确名称↔URL关系硬判错配；未知入口、附件未读转复核，不联网猜内容。
- 常量四则计算用安全解析和精确有理数验算；源计算复述、笔记者复算与新增数字分开处理。
- 明确缺失原话、确定链接错配、错误新增复算和作者元数据冲突进入issues，force不能豁免。
- 每条证据绑定源/稿hash、原始行号与片段；未检查/需语义判断不冒充全文审核通过。
- 真实时序/数值口径、ASR疑点和混合资源关系交批次4，批次0样本与人工确认欠项保留。
## 不做什么
- 不真实抓取、不改生产队列或成品、不运行全库重写；仅本机只读诊断和隔离测试。
