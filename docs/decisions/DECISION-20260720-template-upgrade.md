# 决策清单：笔记总结模板全面升级（去水分 + 新增质量区块）

- 状态：已实现（tests/test_templates.py 11 passed，全量 33 passed）
- 背景：用户评估现有模板质量，要求提升「总结质量 + 排版」、去水分、背景详细、可加案例/正反例/读者互动区等。现状：轻模板(key_points/case/opinion)扎实(8.5)，structured 因「强制9模块」制造水分(6.5)。
- 范围：仅改 `prompts/templates.py` 的模板文本与 UNIVERSAL_RULES；不改 classify / main / 输出链路。

## 关键决策（逐条）

1. structured 去水分：9大「必备」模块改为「核心必备 + 按需可选」。核心=概要/定义/分维度拆解/正反例/延伸思考；工具表·步骤·数据·案例·术语卡「仅原文有才写，没有不凑」，并显式写明禁止编造凑模块。
2. 新增区块按模板性质区别加（用户定）：
   - structured：分层TL;DR、术语卡(可选)、正反例对照、认知误区、延伸思考+✍️留白、可信度标注。
   - key_points：分层TL;DR、正反例(可选)、延伸思考+✍️留白、可信度标注。
   - case：正反例(由「适用边界与坑」升级)、延伸思考+✍️留白、可信度标注。
   - opinion：强化已有【你的思考】为「正反双方+我的立场」决策位、认知误区。
3. 互动区形态按类型：structured/key_points/case → 开放思考题+「✍️ 我的想法：」留白；opinion → 正反双方+「我的立场：___」。
4. 可信度标注：全线加轻量约定——不确定/推断处标「（笔记者推断）」，笔记者补充标「【补充】」，默认视为原文事实，避免编造混入原意。
5. 规则去重：压缩 structured 冗余补丁章节(原九/十/十一互相覆盖)，规则更少更狠；通用项收敛进 UNIVERSAL_RULES 单一来源。
