# DECISION-20261018-a4-video-side

## 背景
A4（长源提取清单）落地后，`videos` 单篇降级路径**经 `dispatch_fields` 顺带注入**（该函数自 2026-10-15 起即传 `source_chars_of`），与 `PIPELINES` §2 原「视频尚未接线」表述不符；且官方 A4 正式轮（84.2%→99.4%）的对照是「同轮新生成稿 vs 评估集历史旧笔记」，混着模板演进，无法归因到 A4。

## 决策
- **视频侧 A4 保留现状**（用户 2026-10-18 裁决）：干净 A/B（12 视频源 / 143 清单条目，两臂 prompt 逐字相同、仅差 A4 的 1446 字规则块）测得保留率合计 94.4% vs 90.2%，而该差值**全部来自单篇孤例 V01**；T2 四源精确打平（含两源反向）；用官方源 + 官方清单的 T1 四篇**两臂皆 100%**。即增量未检出、亦无系统性损害，保留（成本可接受，且保留 `notes/_meta/extract_checklists/` 清单存档副产品）。
- **口径修正**：A4 正式轮的 +15.2pp 应表述为「当前模板 + 重新生成 vs 历史旧稿」，**不是 A4 的净效应**；同期测得历史长源旧稿在该清单上仅 72.0%（10-20k 桶）。本次未改 `PLAN-20261018` 验收记录，待用户复核后另行处理。
- **视频侧全路径均含 A4**（2026-10-18 实测更正）：单篇视频、系列课单集、监控 ASR 批量三条入口都汇到 `videos/main.py:_finalize_single`，降级后用 `dispatch_fields` 生成 prompt（已传源长）→ A4 顺带注入；落盘走 `articles/_save_summary.py` → `save_summary_only` → 剥离生效。例外仅两处：外部 provider 直调分支（`FORCE_AGENT_MODE=0`，默认关）与系列维护脚本 `series_maintenance.py` → `_save_series_note`。
- **更正原「系列未接线」结论**：该结论（含本决策首版）据 `videos/main.py:_build_subagent_prompt` 写成，而该函数**自 2026-07-21 起零调用点（死代码）**；已按实测改写 PIPELINES §2 并在此留痕。

## 不做什么
- 不回退视频侧 A4；不为「一致性」把它扩展到系列单集（无增量收益、只增成本）。
- 不据此结论动模板层结构，也不据「多层复述」立项（判据未立，见下）。
- 不把本决策扩读为「A4 在文章源上无效」——本次样本 12 篇**全部是 B站视频源**（评估集长源桶即纯视频），文章源未测。

## 证据与边界
- 产物：`_tmp/video_a4_ab/REPORT.md`（含逐篇明细）、`_tmp/official_src_a4_ab/`。
- 边界：n=12 源、单一模型单次生成、无重复试验；两套清单（自建 8 源 + 官方 4 源）分组报告不合并。检出「≥+10pp 增益」的能力充分，检出「<5pp 差异」的能力有限。
