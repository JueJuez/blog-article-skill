# DECISION-20261015-batch4-closeout
## 背景
用户授权收尾U2分类及6候选独立全文复审；不再询问已由规则确定的技术选择。
## 决策
- U2当前自动分类为case，另存真实重生成派单与候选，不改历史队列或覆盖生产。
- 作者与审者分离；独立审者先读全源和候选，不读先前问题清单；报告绑定实际输入版本。
- 具体问题至多再修两轮并交原审者复核；仍失败保留候选/问题，不force发布。
- U2锚点含视频文件名和标识数字，根因为正文范围过滤未覆盖文件引用，并且股票代码检测绕开共同数字范围，属于系统性缺口。
- 在共同数字范围剔文件引用，数值及股票代码复用；以RED护栏保护同句真实成本、播放量、股码和同名数字。
- 不降低召回阈值，不添无关数字/链接过门禁；审核状态和机械检查分别报告。
## 不做什么
- 不回填未知历史prompt/作者ID，不修改生产笔记、队列、登记或开启外部provider；不把开发集当留出或人工验收。
## 2026-10-16 G01单次例外

用户明确同意为G01再增加一次定点修订和独立全文复审。仅修复G01-R3-01，把正文比较结论恢复为作者的自我怀疑；旧候选及失败报告保留，新版另存并重新绑定hash。此授权不改变代码/规则的默认两次上限，不豁免复审或生产准入。问题源于表格修订后正文同义表达未同步，属本稿修订遗漏；继续用现有版本失配阻止旧报告认证新稿，由独立全文复审检验语义，不能用关键词断言冒充忠实度判定。
