# DECISION-20260905 · Prompt 模板卫生：READING 编号修复 + 质量自检去重

- **背景**：模板质量评估（同日产出报告）发现两处问题：① `READING_PROMPT` 固定结构双「6.」编号，末条错位到 8（应 9）；② `QUALITY_GATE_SELFCHECK` 六条中 ①②③⑥ 与 `UNIVERSAL_RULES` §八红线逐字级重复，每篇笔记多付约 400 字指令 token。

- **决策 1（编号）**：READING 行动启发→7、延伸思考→8、总结收束→9，固定结构共 9 条。

- **决策 2（去重）**：gate 自检精简为两条非重叠专项——思维模型深挖（原④）+ 固定结构合规（原⑤）；通用红线以 §八为单一真源，自检段不再复述。开头改为「在上文通用规范之外补做」，明确分工。

- **护栏**：新增 `tests/test_prompt_hygiene.py`（12 例）：全部 7 个带固定结构段模板的顶层编号严格递增参数化断言 + gate 去重短语断言 + 专项保留 + 拼接契约。全量 267 passed。

- **教训**：多模板共用「# 固定结构 → # 提炼规范」同构骨架，替换必须锚定模板独有上下文——本次曾误伤 `ROUNDUP_PROMPT`（8→9），被参数化编号测试当场抓住回滚。
