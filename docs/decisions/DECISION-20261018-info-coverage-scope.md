# DECISION-20261018-info-coverage-scope
## 背景
A1 基线归因（52 条丢失逐条归类）显示约 27% 为「整块信息未进笔记」，集中在直播回放/漫谈类源的
散落信息点；模板现行条款「可剔除寒暄、自我介绍、无关铺垫」给这类裁切留了口子。用户当日明确口径。
## 决策
- 用户原话（2026-10-18）：「信息点我觉得可以保留，总结的目的就是尽可能保留有价值的信息，
  如果与论点无关，但实际上信息可能会有所帮助也可以保留」。
- 即：独立信息点（事实/数字/观点/案例/资源入口）即使不在主线，只要可能有帮助就保留；
  「无关铺垫可删」收紧为「重复说法 / 寒暄 / 自我介绍 / 口头语 / 纯过渡句可删」。
- 去水规则不变：重复表达、无源新增、套路填充仍禁；照搬重合 / D相邻段重复 / 140 字压碎句
  等检测保留。边界仍是「写长不是失败；为凑篇幅注水、写长而不重组才是失败」。
- 落地位置：A4 提取清单需含「散落信息点」一类并逐条对账；A6 评估散落信息点在模板中的落点
  （按源形态条件出现，不硬造小节）。
## 不做什么
- 不给字数设上下限（2026-09-15 起即无，保持）。
- 不放松「源里没有的不许编」与机械门禁；实施前不动生产模板。
