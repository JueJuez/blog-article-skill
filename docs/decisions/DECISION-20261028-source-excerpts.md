# 决策：原文素材选取与编排

确认来源：用户在核对 N4 后同意“选取、定位、归组原文素材；只在成稿时按需修改”。

- 提炼模型只输出原文位置、简短主题、必要关联及疑点；素材正文由代码从同版源提取。
- 一个素材可含多段原文，非连续片段明确标界；保留上下文、数字归属、时间与限定词。
- 成稿允许断句、去重复、消解指代与必要衔接，清楚的原文可直接沿用，不逐条强制改写。
- 版本升级后旧材料不自动迁移；沿用派单、回收、装配和机械门禁。
- 范围完整、逐字保真、语义完整和最终成稿质量分别验证；不把复制正确当作选材完整。
- 先做离线保护和一个真实源的有界验证；不默认扩大实验或启用生产。
- 原 N4 的“5 对 4”是模型审计计数，其中两项存在争议；不再作为严格优劣证据。
- 字符规模不等同计费 token 或耗时，原始 N4 记录保留。

原文素材原则保留；历史实施与两源证据见[旧长源计划 §4 N6](../plans/PLAN-20261028-long-source-summary.md)。当前任务与验证只看[流程简化计划](../plans/PLAN-20261028-summary-flow-simplification.md)，消费方式调整见[暂定决策](DECISION-20261028-summary-flow-simplification.md)。
