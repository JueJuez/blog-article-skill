# DECISION-20261018-a4-a6-formal-rounds

## 背景

A4（T0+T15+T6）与 A6（T9 条件必备结构）都已落地，但只跑过 smoke（A4）或离线测量（A6），
**正式对照轮**（PLAN-20261018 §8 Loop 2）未跑。两者都改生成端，§8 归因纪律明令
「不允许两个改动合进同一对照出「84.2%→X%」，那无法归因」。本决策记录**怎么隔离**与**测出了什么**。

## 关键问题：两改动同在 HEAD，如何分离

A6 的生成端改动只有两段模板散文（`COVERAGE_FIRST §4` 散落信息点 / `QUALITY_DISCIPLINE §1`
推广判定），另有 `SECTION_CONTRACTS[*].conditional` 只作用于**门禁**、不进 prompt。
故隔离办法 = 生成 A4 轮时把这两段**按 A4 落地态（commit `4b26a3d`）回退**。

## 决策

- **A4 正式轮**：`build_round.py build --subset all --prompt-profile a4only --round-dir round_A4_formal`。
  `--prompt-profile a4only` 用精确片段替换回退 A6 的两段散文，**定位不到即报错**（不静默跑成未隔离的轮）。
  30 篇全量、同 A1 清单、30 个独立生成 + 30 个独立复核（14 会话，2 篇/人）。
- **A6 正式轮**：`--subset lowretention --prompt-profile current`（A6 开）。子集＝§12.3 #14 指定的
  opinion×4 + structured×2 + 短源对照×2 = 8 篇，与 A4 轮**同 8 篇配对**，唯一变量是 A6。
- **失真观察项（§12.3 #15）**先落地再跑轮：`shared.eval_set.distortion_block/parse_distortion`，
  区在 `MUST_KEEP` 之外（不污染保留率），四类＝范围泛化/方向反转/案例替换/源外数字，口径写回 `ANNOTATION.md` §七。

## 结果

| 轮 | 口径 | 保留率 | 失真 | 变长 |
|---|---|---|---|---|
| A4 正式轮（30 篇，A6 关） | A1 基线 | 84.2%（249/299） | 3 条 | — |
| A4 正式轮 | **A4-only** | **99.4%（297/299）** | **0/30** | **+173%** |
| A6 正式轮（8 篇，A6 开） | 同 8 篇 A4-only | 98.7%（75/76） | 0 | +222% |
| A6 正式轮 | **A4+A6** | 97.4%（74/76） | 0 | +217% |

- **A4**：+15.2pp，17/30 低于目标 → **0/30**；`0-2k/2-5k/5-10k` 全 100%，10-20k 97.2%、>20k 100%。
- **A6 增量 = −1 条**（A24 +1 / A28 −2）＝在 76 条规模上的**生成方差，非 A6 效应**
  （A28 在 A4-only 轮是 10/10；A6 那两段是**更宽松**的保留条款，不会致漏）。
- **A6 结构硬拦实测**（对两轮新稿）：A4 轮 30 篇触发 3 例、缺节 **0**；A6 轮 8 篇触发 1 例、缺节 **0**
  → 误报 0，与离线 1298 篇（35 触发/1 缺节）一致。**A6 在保留率与长度上无可测增量**，其可验收部分是硬拦误报率。

## 必须同读的三条边界（口径）

1. **基线是库里的历史稿**（更早版本 prompt 生成）→ 84.2%→99.4% 是「当前整套生产提示词 vs 历史稿」的差，
   **不等于 A4 单步的差**。这是计划既定对照设计（同 §8 Loop 1）。
2. **两数同族 AI 判定，可比的是差值**；99.4% 近天花板，该指标在长源桶的区分度接近耗尽。
3. **副作用**：prompt 二次修订把超长句从 smoke 的 75% 压到 **50%**，但**变长 +173% 未被压下**（smoke +174%）。
   即该修订对「超长句」部分有效、对「变长」无效 → 笔记 2.7 倍长是遗留观察项（下游检索上下文变贵）。

## 不做什么

- 不加「regenerate with pre-A4 prompt」的第四条对照臂——那能把 A4 单步从「提示词漂移」里摘干净，
  但成本再翻一倍且计划未要求；本决策按 §8 既定设计执行，并把漂移边界如实写进结论。
  **补记（2026-10-18 晚）**：该第四臂**已按干净 A/B 补跑**（12 个 B站视频源 / 143 条清单；两臂 prompt
  逐字相同、仅差 A4 的 1446 字规则块；其中 4 篇用本评估集长源 + 官方 A1 清单复刻）→ **A4 单步增量未检出**：
  合计 94.4%（无 A4）vs 90.2%（含 A4），而该差值**全部来自单篇孤例 V01**（V01 的负信号在扩样后未复现）；
  用官方源 + 官方清单的 4 篇**两臂皆 100%**。故上文「99.4%」应读作**「当前整套生产提示词 + 重新生成 vs 历史旧稿」**，
  A4 单步贡献未检出。完整数据、边界与保留决定见 [DECISION-20261018-a4-video-side](DECISION-20261018-a4-video-side.md)。
- 不把 A6 的「无可测增量」读成「A6 无效」：它的定位是低召回安全网，测得的是**误报率 0**，不是覆盖率。
