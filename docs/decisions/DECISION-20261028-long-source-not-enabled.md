# 决策：长源两阶段提炼不启用（2026-10-28）

状态：v4 试验结论保留，生产开关仍默认 `0`。后续用户确认 [N6 原文素材候选](DECISION-20261028-source-excerpts.md)，不沿用本轮质量结论评价新方案。
关联：[长源总结效率与质量计划](../plans/PLAN-20261028-long-source-summary.md) §4 N4；[新计划决策](DECISION-20261028-long-source-summary.md)

## 问题

长源两阶段（结构切分 → 分块提炼 → 全篇统稿）在 N1–N3 只完成离线实现。N4 要回答：它值不值得接生产。

## 实测（N4，2026-10-28）

样本：S3 长字幕 35,155 字、D1 长文章 19,724 字，均按现役路由判 `distill/long_source` 单块。臂：现役单轮 vs 两阶段（v4 契约，材料包 20.9k/30.3k 字符）；S3 另加 v2 细条目对照臂。相同写作 prompt 主体、同会话模型、每臂一次生成、每样本一名独立审者盲比。

- 质量：两源 P1 遗漏均 0:0；D1 上两阶段确定性失真 5 vs 单轮 4（含归属反转）；S3 上 P2 细节丢失 12 vs 9；机械门 D1 上两阶段更干净、语义上反而更差。
- 成本：端到端输入 S3 +165%、D1 +196%，调用 2×；写作调用 token 亦更高。
- 粒度本身：v4 相对 v2 材料 -63%、条目 -82%、关系 107→13，但合并丢失读数口径（兼职/顾问 80–100 万被并、两说并成单区间、本科 4 年时序错置）。

## 决定

**不启用**。`NOTE_DISTILL_DISPATCH` 固定 `0`，不做有限启用评估；设备留作离线能力（版本门、切分、全块回收门、统稿契约全部保留并有测试）。N5 只做收口：真实队列幂等/剥包证据、缺陷索引（D11–D13）、文档同步。

## 理由

1. 保留门槛（计划 §5.5）四条只满足「粒度对照有成本改善」一条；质量改善在两个不同适用源上都没出现，反而在长文章上多一条确定性失真。
2. 端到端成本方向与假设相反：多一遍全文输入和一次调用，抵消了材料变短的收益；「输入变短」只发生在材料包，不发生在总输入。
3. 材料审计给出可复现的失败模式：段级论证单元倾向于把同一论证里的多个读数并成一句，正好触发「数字归属/口径不可混」这条底线。

## 边界

单样本单生成，结论只覆盖「本次条件下无改善」，不外推为「两阶段永远无用」；数字密集类仍在路由层排除，未测；多块路径没有真实样本（见 D13）。重启条件：先修契约的读数分列与段级已读声明，再用 1 个源复测，仍无可定位改善则不再投入。
