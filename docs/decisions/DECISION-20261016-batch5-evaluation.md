# DECISION-20261016-batch5-evaluation
## 背景
用户要求开始批次5；批次4的6份开发候选独立文字复审已通过，不代表整体验收。
## 决策
- 首轮选择D02、S02两项已知错配和H01候选留出；2026-10-17续补D01真访谈、C1案例及B01单集讲书，全部冻结源和prompt。
- 三组为c9d6630自动分类+旧契约、Agent建议类型+旧契约、当前自动分类+新契约；第二组不是人工确认。
- 同一会话Agent生成方式、相同任务指令、不指定模型覆盖；模型/采样参数未暴露，不能称严格受控模型实验。
- 分别由未读其他候选的生成者输出原始稿；隐藏版本标签，由不同Agent先列源要点再全文比较。
- 续补组旧自动与建议类型相同、prompt相同时只生成一次，明确两个策略共用同一基线，不当作两次独立重复。
- 保留原始失败稿，不把定向修订后成绩计入原始生成效果；记录可见耗时、次数和修订量，费用未知记not_exposed。
- H01仅证明不在17组清单，不证明跨历史会话从未接触；没有改prompt前暂作候选留出，不夸称严格留出。
- 不改生产、默认开关或外部provider，不启动抓取；人工标注、有效书评/横评、全形态及真实成本仍为欠项。
## 不做什么
- 不把旧库成品当同条件基线，不将Agent评分或静态测试当整体质量通过，不据首轮结果批量修库。
