# DECISION-20261018-batch5-closeout
## 背景
用户询问批次5（PLAN-20261014）剩余项（严格留出/人工标注/实测费用）是否还需要继续。
评估：新模板契约早已是在产代码，留出验证的对象会被后续改动取代；存量修订的准入
已由 T13 必要性判断承担；人工保留率的功能由 A1 评估集（分层、可复现、可重测）接替；
费用项独立于冻结、随时可补。
## 决策
- 批次5 按**有限验证**收尾：wave1~7 已完成证据全部保留生效；留出/人工标注/费用三项
  不再执行；不得改写为「整体验收通过」。
- 质量模块（门禁/分类器/模板）解冻：知识层 T8 / A4(T0+T15+T6) / A5(T5) / A6(T9) 即可开发。
- 材料原样保留（留出候选池 2288 缓存登记、人工包 21 源、各 wave 私有目录）；
  如需重启，重新冻结到当时的源+prompt+代码状态并另行记录。
- 缺口如实登记：无严格留出证据、无批次5 人工保留率、费用 not_exposed。
## 不做什么
- 不授权全库批量重写：存量重做仍走 T13 → 批次 → 受控替换（T8）→ 抽检的现行流程。
- 不把测试通过或 Agent 评分当整体语义验收。
