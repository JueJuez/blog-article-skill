# DECISION-20261028-long-source-summary
## 背景
用户于 2026-10-28 确认优化长源总结效率，并要求先裁定旧计划遗留再建立清晰的新计划。
## 决策
- 短源保留整篇单轮；长源按结构切分、分块提炼、全篇统稿，全部源块均需处理。
- 提炼以完整论证为单位，数字及条件就近保留；段内关系直接表达，跨段关系仅按必要记录，不强制逐数字拆条和完整关系图。
- 复用原文、行号、材料索引、版本绑定、派单、公共保存与有界审核；新旧契约不可混用，失败与部分产物不可冒充完整。
- RAG 暂只借鉴定位和回源，不引入向量库或用 top-K 代替全文总结。
- [旧计划](../plans/PLAN-20261026-low-cost-quality.md)退役为历史，未完成不记通过；迁移裁定、当前任务与验收只维护于[新计划](../plans/PLAN-20261028-long-source-summary.md)。
- S2/S4 否决不复活，S5 等已完成能力不重做；输入成本、分块稳定性、独立语义复验和必要遗留分别承接。
- 开关在满足新计划出口前保持默认关闭；旧 S1 额度不因计划迁移重置，有限试验不外推全库。
## 不做什么
本次只整理计划与导航，不实现功能、不运行模型或修改生产配置/队列/旧库；不把退役、文档检查或历史测试称为整体质量验收。
