# DECISION-20261029-gate-audit

状态：生效（2026-10-29 用户拍板两次：① 路由改按内容类型；② 数值保真门禁先 shadow 两周再启用）。

## 背景

2026-10-29 复核「数字密度 0.08 / 不同数字串 130」两道路由闸，以及既有门禁体系是否随业务迭代过期。
只读实测（全库 2421 个 `_raw_` 源，其中 ≥10000 字 139 篇）：

| 观测 | 结果 |
|---|---|
| 闸①（密度 ≥0.08 → 单轮） | 全库零作用：26 篇数字密集源的不同数字串最低 156，本就会被闸②拦住；只删闸①，路由变化 0 篇 |
| 闸②（不同数字串 ≥130 → 单轮） | 阈值落在空带：107 篇组合源最大 115，被拦侧最小 155 |
| 只删闸② / 两闸全删 | +6 篇 / +32 篇改走两阶段 |
| 被拦的 32 篇是什么 | 教程 1 篇；估值/公司分析 26 篇；框架类 11 篇（与前类重叠）；无类别词 4 篇（黄金观点文 ×2、中金宏观、联合研究） |

结论：这两道闸拦的不是「数字多」，而是「时效内容」——判据错了对象，且阈值本身可调，
等于没有判据。用户原话：「一个好的门禁，不应该是可以随便改参数的。」

## 决定

### 1. 路由判据改为内容类型（`shared/source_types.py`）

- 判据 = **信息半衰期 / 可沉淀性**，只看体裁类别词的存在性，**不含任何数值阈值**。
- 映射：教程与**系列课**（缠论 / 交易体系 / 波浪理论 / 技术分析等成体系课程，2026-10-29 用户追加）
  → 两阶段（提炼 + 按 pack 写作）；观点 / 研报 / 宏观 / 行情复盘 / 公司基本面分析 /
  框架方法论 → 单轮；未识别 → 两阶段。
- 理由（用户 2026-10-29）：「11 篇深度商业分析看结论，如果要分析框架，我完全可以另起一篇笔记记录框架」；
  黄金观点文 / 中金宏观 / 联合研究同理；只有教程类值得投组合路径保质量。
- 删除 `DENSE_DIGIT_DENSITY`、`NUMERIC_HEAVY_UNIQUE_NUMS` 与对应判定；保留 `LONG_SOURCE_MIN_CHARS`
  并改注为**成本边界**（两阶段对短源不划算）。
- 未识别不静默降级：偏好方向是「多花一次提炼成本」，不是「悄悄降质」（68 篇无类别词长源因此保持组合）。

### 2. 门禁三分法

| 层 | 判据 | 处置 |
|---|---|---|
| 门禁 | 二值、不可调参（H1 / 来源链接 / URL / 字数上下限 / 证据确定缺陷 / 新增数值保真） | 拦落盘，按 issues 修稿重交 |
| 观测 | 比例类（锚点召回、照搬重合、结构缺失、破碎形态） | 只报 `review_flags`，不拦盘；消费须显式 |
| 策略 | 类别清单与成本边界（`source_types` / `LONG_SOURCE_MIN_CHARS`） | 改表须拿真实标题重新测量，不凭手感调 |

### 3. 数值保真门禁先 shadow，两周后启用

- 判据（二值，无阈值）：① 带单位数字串必须在源里逐字存在（千分位 / 空格 / 全角百分号归一后比较）；
  ② 取整或换算出的数字，同一行必须保留源原串；③ 无源可接地时不检查。
- 实现：`prompts/numeric_fidelity.py`，在 `save_summary_only`（文章/队列）、
  `videos._summarize_and_save`（实时视频）、`videos._save_series_note`（系列课）三条落盘路径的
  机械门禁之后执行；合并逻辑共用 `apply_to_gate`（`shadow`/`off` 原样返回，只有 `block`
  未通过才把 issues 并进门禁，`force` 不豁免）。
- `NUMERIC_FIDELITY_GATE` 默认 `shadow`：只写 `notes/_meta/numeric_fidelity.jsonl`，**绝不拦盘**；
  观测两周（自 2026-10-29 起）后切 `block` 才并入拦截；`off` 关闭；未知取值回落 `shadow`。
