# DECISION-20261027-input-and-output-scope
## 背景
用户于 2026-10-27 确认输入优化方向与输出目的，要求先记录开发计划，再讨论输出模板和内容质量；下方正文保留最初讨论时点。2026-10-28 起[原计划](../plans/PLAN-20261026-low-cost-quality.md)退役为历史，任务与验收迁至[新计划](../plans/PLAN-20261028-long-source-summary.md)；目标与输出边界保留，提炼粒度的后续选择见[新决策](DECISION-20261028-long-source-summary.md)。
## 决策
- 项目继续主打自动监控、抓取与总结，内容总结和知识笔记面向下游 Agent 提供完整、可追溯、便于取材的源内信息，不据此新增模板类型。
- 完整包含主线、独立信息、证据关系、条件与反例；主线外有独立价值的信息保留，重复可合并，重要陈述能回源，片段保有必要上下文。
- 允许重组与源内归纳；延伸分析、外部补充、反驳、类比和迁移建议当前不做，以后另行优化。现有模板冲突条款待统一，尚未改生产。
- 输入按原文提炼后再适配模板；抓取工具保结构与读取范围，提炼交付主线地图、信息条目、关系说明，写作和复核保留原文回查。
- 独立提炼与上下文隔离先在长源、复杂论证或图文材料做受控试验；多 Agent 方向不等于净收益已验证，未证明适用前不全量接入。
- 用户要求将模板/内容质量讨论写入原计划：保留九类入口并微调公共规则和栏目，额外延伸关闭，作者原有分析仍保留；正文表达顺序可受约束地重组。
- 编排保护原意、独有信息、证据归属、条件、时序和问答对应；同步模板、结构门禁与审核口径，避免指令冲突，生产尚未调整。
- 新提出的质检最小方案见原计划 §9.9：检查依据、保真、遗漏和取材可用性，复用既有有界审核；本次只记录建议，未启用新质检行为。
- 沿用[原开发计划](../plans/PLAN-20261026-low-cost-quality.md) §2/§9 作为任务与验收真源，保留 S1–S4 记录；讨论已全部记录，下一会话按 §8.3 从 S5 开发接手，不重复确认既定方向。
  - **后续状态指针（2026-10-28）**：上条「从 S5 接手」、正文「尚未改生产」及旧计划的任务入口均为历史；当前只按新计划 §4 的 N1 接手，旧项迁移/取代/不迁移理由见新计划 §3，本决策不再复制阶段进度。
## 不做什么
本次不写功能、不调用模型、不改生产 prompt 或全量流程、不重写旧库；不复活 S2 薄清单试验，不重开知识层 B 组或下游系统改造。
