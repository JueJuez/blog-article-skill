# DECISION-20261015-type-provenance
## 背景
按已授权计划批次2修复孤词误路由和类型来源丢失；批次0欠项继续保留。
## 决策
- 分类用主线标题、说话者关系和比较结构等组合证据，证据不足回退general并记录理由；不新增模型调用。
- 显式type为manual；旧条目无法证明来源时为legacy，不从type值或日期猜来源。
- 新派单记录源文本UTF-8 SHA256、实际模板prompt SHA256、type、来源、分类规则版本与理由；审核默认未执行。
- 已知auto刷新type与prompt；manual保留；legacy只报告建议差异，保留原type和路径。
- 默认过滤命令保留原有行为，新增--dry-run用于只读预览；本次只运行只读生产报告。
- 元数据经现有保存链路进入登记表，不参与去重键/文件名；旧记录读取补unknown，不回填虚构版本。
- prompt hash明确标模板/派单范围，不冒充包含所有分块、重试和元信息的模型调用记录。
## 不做什么
- 不改生产队列、不覆盖vault、不补造人工标注或全文审核通过，不将规则回归当留出语义验收。
