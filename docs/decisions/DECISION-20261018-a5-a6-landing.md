# DECISION-20261018-a5-a6-landing
## 背景
A 组最后两项（A5 论点级判据 T5 / A6 条件必备结构 T9）落地，两者都改生成端或门禁，
按 PLAN-20261018 §12.3 必须先定判据级别与阈值。
## 决策
- **A6（T9）落地为硬拦，但阈值从严且先测后上**：源侧机械信号五个（反例/公式/章节/对比/数值密集），
  只认明确标记与可数结构，不认语感；信号触发时该小节升为必备。**离线实测 1298 篇**：信号总触发 35 例
  （最高 formula 24 例）、触发但缺该节**仅 1 例**（疑别名过字面）→ 误报率极低，故可作硬拦。
  代价如实记录：**召回很低**（约 2.7% 篇目触发），它是安全网，不是覆盖率驱动。
  与 `required`（无条件）分开配置：`SECTION_CONTRACTS[*].conditional = {小节: 信号名}`。
- **A5（T5）落地为纯报告项，且明确禁止当指标用**：机械半 = 源侧断言候选 + 「疑似无落点」+ 两列失真嫌疑
  （笔记里源中不存在的数字 / 方向词反转）。**实测校准结论（30 篇）**：机械覆盖率与 A1 手工保留率
  相关性极弱（r≈0.17~0.20，单篇甚至反向：A27 机械 0.17/手工 0.83）→ **机械覆盖率不得作为分数、
  不得进门禁、不得用于判「笔记不合格」**；它只产「该核什么」的清单。
  真正低误报可机械用的是失真嫌疑（源外数字 10/30 篇、方向反转 1/30 篇）。宿主＝A3 落盘后异步审核，
  机械前置注入派单、判定权交独立审者；规模天然等于「评估集 + 15% 抽检」，不另起队列。
- **A6 模板侧同步收紧**：`COVERAGE_FIRST §4` 删的边界改为「重复/寒暄/自我介绍/口头语/纯过渡」，
  **明确「与论点无关」不再是删的理由**（散落信息点照原意保留）；`QUALITY_DISCIPLINE §1` 推广判定
  按上下文绑定（孤立纯推广删 / 流程内推广保留并标【推广】）。
## 不做什么
- 不给 A5 出覆盖率分数或阈值；不把 A5 的机械结果升级为拦盘/重交信号。
- 不为 A6 加「语感类」信号（如时间线密度——暂无小节与之映射，宁缺不配）。
- 不动 `required`（无条件必备）的既有语义与阈值。
