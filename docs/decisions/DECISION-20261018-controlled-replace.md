# DECISION-20261018-controlled-replace
## 背景
重做入口原为「过门禁即覆盖」：门禁只拦不合格、不衡量是否比旧稿更好，一版修掉旧缺陷
又引入新缺陷的稿子也会直接盖掉旧稿，而库无版本历史（覆盖即终身）。T13 解决「该不该改」，
本决定解决「改了怎么换」。
## 决策
- 判定**零新增判据**：用 T13 同一套确定性缺陷（锚点召回/照搬/结构缺失 + 证据确定性缺陷）
  对旧稿与候选稿各算一次，**明确更少才替换**；平手/更差保留旧稿（「也可以选择不改」）。
- 候选稿在替换判定前先暂存（含三 hash）；决策回写暂存 meta 并追加
  `notes/_meta/replace_decisions.jsonl` 台账（action/reason/新旧缺陷数）。
- `--force` 跳过比较无条件替换（逃生舱，兼作内容门禁豁免；机械门禁不豁免）。
- 语义腿沿用 `admit_candidate`：带独立审核报告（`review_required`）时强制
  独立会话/全文覆盖/passed，不过即抛错（稿进暂存）。
## 不做什么
- 不为「看起来更好」引入形态/软信号权重（未标定，会拦住无伤大雅的替换）。
- 不替代批量重做前的旧版备份：`scripts/archive_old_before_resum.py` 照旧使用。
