# DECISION-20261018-ai-annotation
## 背景
A1 评估集的必留清单原定「人工标」（PLAN-20261014 §10.6 / PLAN-20261018 §6 A1）。用户 2026-10-18
决定：不人工填表（太慢），改由独立的子 Agent 按固定口径标注。这改变了计划里声明的口径，
需要把方法与边界写清楚。
## 决策
- 标注由**独立子 Agent**执行（不与生成会话共享上下文），两阶段隔离：
  ① 先只读源、写出必留清单（此阶段不许打开笔记）→ ② 才打开笔记逐条判断是否实质保留。
- 口径固定并写入任务文本：数字口径 / 作者观点（方向与强度）/ 支撑案例 / 前提条件与限制 /
  反例例外 / 资源入口；每条自包含、可指回源位置；条目数 5~12。
- 产物性质如实标注为 **AI 标注基线**：绝对保留率与人工基线不可混称（标注与生成同族模型，
  存在乐观偏差风险）；其用途是**改动前 vs 改动后的同口径对照**。
- 表单防覆盖护栏（已填即拒重建）同样保护 AI 标注产物。
## 不做什么
- 不声称这批数字等同人工验收或「人工标注已完成」；不据此宣布模板整体通过。
- 不因为标注改了方式就改动评分口径（仍是 保留数/清单条数、≥3 条起算、目标 90% 参考）。
- 人工校准仍可随时做：任选若干张复核/修正即可（表单格式与判分不变）。
