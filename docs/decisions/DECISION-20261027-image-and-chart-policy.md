# DECISION-20261027-image-and-chart-policy
## 背景
用户在本会话确认按需读源图、按用途生成图表，并要求更新原计划后由新会话实施；[原阶段决策](DECISION-20261026-low-cost-quality.md)的 S1/S2 结论与成本边界保留。
## 决策
- 源图用于补正文未覆盖的知识；按需读取、文字化，必要时保存原图及来源供回看，单存图片不算当前文本取材可用。
- 装饰/重复图通常跳过；图不可达或含义不清明确记缺口，不凭 alt 推测。
- 成稿按比较/关系/趋势选择 Markdown 表格、Mermaid 或 chart；每篇判断，允许零图零表，不凑配额。
- 箭头数、链长、数字组数只作候选信号；取代原 S4“按机械量强制画图”候选，无图统计不算质量缺陷证据。
- 先核验 S3 真实主源重要图，再推进 S4 隔离配对；表达试验可复用冻结文本，未证明收益前不改生产默认。
- 生成时机为读懂源并确定组织后随成稿生成；保存前核对事实、数字口径与结构关系，渲染不代替语义验证。
## 不做什么
不全量 OCR/保存所有原图、不另加绘图模型、不全库重写，不扩 D6 通用校验或 D7/D8；本决策保留当时范围，图像/图表试验证据见[旧计划](../plans/PLAN-20261026-low-cost-quality.md)。2026-10-28 起任务与验收以[新计划](../plans/PLAN-20261028-long-source-summary.md)为准，重要图消费承接 Q3，S4 否决不重开。
